# Skins Remake V1 — один архив вместо тысячи картинок

**Статус:** не начат
**Когда делать:** пока игроков меньше 300–500. Лучше заранее, чтобы потом не переделывать.
**Зачем:** сейчас каждый игрок скачивает PNG каждого игрока, которого увидел. На 1000+ игроков
это тысячи загрузок с GitHub Pages и почти полный лимит бесплатного трафика.

## Что изменить

1. **Один файл вместо многих.** Хранить скины в одном `skins.zip` на сайте
   `https://felixzufa-design.github.io/skins/skins.zip`.
   Внутри: `skins.json` (ник → имя файла, без длинных ссылок) и папка `png/` с картинками.
2. **Мод качает архив сам.** Вместо проверки и загрузки каждого PNG:
   - раз в час (или при первом входе в мир) сравнить, стоит ли локальная копия
     (`Etag` / `Last-Modified` или размер), и скачать архив, если он обновился;
   - распаковать в `config/qdskins/skins/`, зарегистрировать текстуры;
   - кэш картинок и `skins.json`-загрузку из интернета убрать.
3. **Не перекачивать без изменений.** В `skins.json` оставить поле версии пакета: если версия
   прежняя, архив не трогаем.

## Файлы

- Мод: `dist/_mdk_tmp/skinmod/src/main/java/ru/qdshnik/qdskins/SkinManager.java` —
  `lookupTexture`/`downloadAsync`/`refreshJsonAsync` заменяются одним `syncPack()` (скачать архив,
  распаковать, зарегистрировать).
- Сайт: `felixzufa-design/skins` — добавить `skins.zip` и скрипт/инструкцию сборки:
  PNG из `skins/` + `skins.json` → zip.
- Проект: `skins/` — папка с исходными PNG, генерировать zip локально скриптом.

## Что останется как есть

- Миксин `AbstractClientPlayerMixin` (инъекция в `RETURN`): приоритет других модов
  (Ronova и любых) сохраняется.
- Лаунчер и `manifest.json` менять не нужно — мод остаётся тем же `mods/qdskins-X.Y.Z.jar`.
- Адрес `skinsUrl` в конфиге мода остаётся, просто станет указывать на архив.

## Выпуск

1. `mod_version++` в `gradle.properties`, `./gradlew build --no-daemon`,
   перезаписать `META-INF/neoforge.mods.toml` (шаблон в `SKINS_RUNBOOK.md`).
2. Обновить `manifest.json` (size + sha256), пересоздать `manifest.json` в релизе
   (удалить файл из релиза → залить заново, `--clobber` не обновляет CDN), удалить старый jar.
3. Собрать `skins.zip` из `skins/` и `skins.json`, залить в `felixzufa-design/skins`.
4. Сказать игрокам перезапустить лаунчер.

## Проверка

- Свежий игрок (пустой кэш) заходит в мир → все скины загрузились одним запросом.
- Новый PNG добавили на сайт → в течение часа у игроков в игре, без перезахода.
- У игрока с Ronova скин Ronova остаётся.

## Риски и решения

- **GitHub Pages ограничивает трафик.** Архив раз ~500 скинов × 9 КБ ≈ 4,5 МБ и скачивается
  раз в час на игрока, а PNG больше не качаются. При 10 000 игроков это уже много трафика —
  тогда нужен другой хостинг файлов (не GitHub), деньги.
- **Распаковка на клиенте.** Использовать встроенный `java.util.zip`, без сторонних библиотек.
- **Битый PNG.** Проверять размер при распаковке, пропускать неверные с предупреждением в лог.

## Отложенные идеи

- `skins.json` без дублей: поле `base` (общий префикс) + `{ "Nick": "Nick.png" }`.
- Удаление из пакета скинов игроков, которых давно не было на сервере.
- Отдельный скрипт `make_skins_zip.py` в проекте (PNG → zip + пересчёт).
