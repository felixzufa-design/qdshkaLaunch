# Скины по нику — как поправить без программиста

Мод `qdskins` ставит каждому игроку PNG-скин по нику. Список скинов — файл
`skins.json` на сайте `https://felixzufa-design.github.io/skins/`.
Мод у игроков скачивается лаунчером автоматически.

## Добавить игроку скин

1. Скачай скин в формате **PNG 64×64** (или 64×32).
2. На GitHub открой `felixzufa-design/skins` → кнопка **Add file** → **Upload files** →
   перетащи картинку. Назови файл **точно как ник в игре**, например `Nick.png`.
3. В том же репозитории открой `skins.json` → карандаш ✏️ и добавь строку:
   ```json
   "Nick": "https://felixzufa-design.github.io/skins/Nick.png"
   ```
   Между строками — запятая, после последней строки запятой не должно быть.
4. **Commit changes**. Подожди 1–2 минуты.
5. Проверь: открой в браузере `https://felixzufa-design.github.io/skins/Nick.png` —
   должна открыться картинка. Если ошибка 404 — подожди ещё минуту.

## Добавить плащ (и элитры)

Плащ рисуется так же, как на лицензии: если плащ есть в записи игрока, он
появляется на спине и на элитрах (в 1.21.1 элитры берут текстуру плаща).

1. PNG плаща **64×32** (или 64×64). На сайт его надо положить в папку `capes/`
   с именем по нику: `capes/Nick.png`.
2. В `skins.json` запись игрока с плащом выглядит так:
   ```json
   "Nick": {
     "skin": "https://felixzufa-design.github.io/skins/Nick.png",
     "cape": "https://felixzufa-design.github.io/skins/capes/Nick.png"
   }
   ```
   Если плащ не нужен — можно оставить старую форму (просто ссылка в кавычках).
3. Проверь ссылку на `capes/Nick.png` в браузере, игрокам — перезайти.

Настоящий плащ с лицензии (Mojang) мод не перезаписывает.

## Поменять скин

Загрузи новый PNG с тем же именем поверх старого (Upload files → заменит). Список
`skins.json` трогать не нужно. Игроку нужно перезайти на сервер.

## Что важно

- Ник в `skins.json` пишется так же, как игрок входит (регистр не важен).
- Скин виден только игрокам, играющим через лаунчер.
- Список обновляется у игрока примерно раз в 5 минут.
- Ошибка `not a valid mod file` — проблема сборки мода (её лечит только Claude/программист),
  не проблема скинов.
- Скины других модов (например Ronova) не перекрываются — они остаются как есть.

## Полная инструкция для разработчика

`SKINS_RUNBOOK.md` — сборка мода, выпуск версии, публикация manifest.json.
